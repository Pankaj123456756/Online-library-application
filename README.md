Online Library Application

An Online Library Management System built using Java (Spring Boot) for backend and JavaScript frontend, designed to manage books, users, and library operations through a web interface.

This project demonstrates full-stack development, REST APIs, and containerized deployment using Docker.

🚀 Features

📖 View all books in the library

➕ Add new books

✏ Update book details

❌ Delete books

🔍 Search and manage book records

🌐 Web-based user interface

🔗 RESTful API communication between frontend and backend

🐳 Docker support for easy deployment
